# Bunk Planner 1.7.0 — Release notes

## What's new

- **Mark all subjects today** — Log Yes / Missed / Holiday for every subject on your timetable in one place (morning & evening prompts).
- **Classes left this semester** — See remaining classes on Home and Overview (timetable × weeks − holidays − planned bunks).
- **Home & Lock Screen widgets** — Glance current % and safe bunks without opening the app.
- **Focus Timer** — Pomodoro-style 25/5 study timer on the Academics tab, with end notifications and today’s focus minutes.
